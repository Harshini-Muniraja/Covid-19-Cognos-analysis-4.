# COVID-19 Cases Analysis (Data Analytics with Cognos)

Team project (5 members) from the Next Gen Employability Program. The goal was to analyse COVID-19 cases and deaths data, compare the mean and standard deviation of daily cases and deaths, and design an interactive IBM Cognos dashboard for healthcare professionals, policymakers and the public.

## What is in this repository

| Folder | Contents |
| --- | --- |
| `docs/` | Documentation for each project phase (problem definition and design thinking, project plan, development parts 1 and 2, final documentation) |
| `notebooks/` | `phase3_data_exploration.ipynb`: loads the dataset with pandas, checks missing values and data types, prints summary statistics, and plots trends with matplotlib |
| `data/` | Instructions for downloading the dataset |

## Tools

Python, pandas, NumPy, Matplotlib, Jupyter Notebook; IBM Cognos Analytics (dashboard design, as described in the phase documents).

## How to run the notebook

1. Download the dataset as described in `data/README.md`.
2. `pip install pandas numpy matplotlib notebook`
3. `jupyter notebook notebooks/phase3_data_exploration.ipynb`
